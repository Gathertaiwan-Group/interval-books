# 布苔球活動封面設計

## 目的

為「植生布植生牆｜布苔球」補上一張符合小時光書店氣質的活動封面，讓活動列表與詳情頁不再只有文字。

## 視覺方向

- 自然編輯攝影風，方形構圖。
- 主體是一顆以灰綠植生布包覆的苔球，長出細緻蕨類。
- 場景為自然光下的木質工作桌，背景帶有柔焦書架與綠意。
- 色彩使用苔綠、鼠尾草灰、木色與亞麻米色。
- 不放人物、文字、Logo 或浮水印，避免生成錯字並保留多語網站的通用性。

## 上架方式

將生成圖放入官網公開素材目錄，部署後以正式站圖片網址匯入網站圖片庫，再把回傳的圖片 key 設為活動封面。正式寫入前先執行內容管理工具的 dry run，確認只改 `image_key`。

## 驗收

- 圖片主體清楚，裁切成活動卡片時仍能辨識布苔球。
- 正式網址可讀取圖片。
- 活動資料的 `image_key` 從空白改為新圖片 key。
- 活動標題、票價、場次、票種與名額均不變。
